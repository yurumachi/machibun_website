# モックの確認メモ

範囲は `docs/mock-scope.md` のとおり。ここまで作ったところで止めて、好みで決める項目を下にまとめた。

## 見かた

`docs/prototype/mock/index.html` をブラウザで直接開く（サーバーは要らない）。左下のパネルで、動きの量と blob の量・濃さを切り替えられる。右下のボタンで動きが止まる。出展者のカードを押すと詳細ページ（`docs/prototype/mock/exhibitor.html`）が開く。

## 作ったもの

- ファーストビュー: チケット型の枠（切り欠き・ミシン目・半券）、チラシから取り出したロゴ（SVG）と線画、漂う blob
- お知らせ、出展者30件（写真なし・長い店名・英語の店名・長い紹介文を混ぜた）、タイムテーブル、協賛（広告バナー1枠・ロゴ2段・名前のみ1段）、開催情報
- 出展者の詳細ページ（CMS のリッチテキストを想定した見出し・リスト・リンク）
- 動き: blob の形と位置、線画の揺れ、見出しの波線を流れるグラデーション、カードのホバー、波線の境界、スクロールで膨らむ blob（Chrome / Safari 26 以降。Firefox では静止）

デザインシステムへの追加は `docs/prototype/css/tokens.css` と `docs/prototype/css/style.css` に入れた（モック専用ではない）。モック専用のものは `docs/prototype/mock/mock.css` と `docs/prototype/mock/mock.js` の後半だけで、本番では消す。元のサンプルページ（`docs/prototype/index.html`）にも、灰色の帯が消えた blob と見出しの波線が反映される（崩れはないことを確認済み）。`DESIGN.md` への部品の追記は、下の好みの項目が決まってから行う。

## チラシから変えたところ

- 背景と面の色は、今のテーマ（#1A1B20 / #24262C）のまま。チラシの濃紺にはしていない。
- blob の配色は、テーマのグラデーションの4色を組み合わせ直した。チラシの赤茶・オリーブは使っていない。
- 線画はチラシに画像で埋め込まれていたものを WebP にしただけで、ベクターではない。
- 日付（10.3 sat）とキャッチコピーは仮の文言。キャッチコピーは 2024 年のものを流用している。

## 決まったこと（2026-10-13）

- 画面幅は4段階: スマホ 〜767px / iPad 縦 768〜1023px / iPad 横・ノート PC 1024〜1439px / 広い画面 1440px〜。チケットを横に並べるのは 1024px から
- 1024px からファーストビューは全面ビジュアル（画面の高さいっぱい、blob を画面全体に散らす）。1440px からはチケットの左右に線画を置き、出展者・協賛の一覧を本文より広げる
- スマホは画面下のタブバー。ヘッダーは全幅でスクロールに付いてくる。動きを止めるボタンはヘッダーの中
- blob はチラシのような尖りとくびれのある形（`clip-path: shape()`、`docs/prototype/scripts/gen-blob-shapes.py` で生成）。非対応ブラウザでは楕円になる
- blob の濃さの選択肢は今のまま（0.4 / 0.55）。透明度は blob の群れにまとめてかけ、重なった部分が明るくならないようにした

## 決まったこと（2026-10-14）

- 動きの量は「にぎやか」、blob の濃さは 0.55。どちらも `docs/prototype/css/tokens.css` の既定値にし、モックの切り替えから外した
- 0.55 では、blob の明るい部分に重なった白い本文が 4.5:1 を割る（最悪で約 3.3:1）。いったんこのまま進め、公開前に重なる箇所を測って、割れていれば本文の下に面を敷く
- 動きを止めるボタンは本番にも残す（WCAG 2.2.2: 5秒を超えて自動で動くものには止める手段が要る）。本番で消すのは左下のモック用パネルだけ
- キャッチコピー「夜のまち、みんなが耀く、舞台となれ。」は差し替わる見込み。CMS には載せず HTML に直接書く。差し替えたときに崩れないかは、そのときに確かめる

## 決まったこと（2026-11-02）

- 1440px からも、出展者・協賛の一覧は本文と同じ幅にする（10-13 の「本文より広げる」はやめた）。広げた一覧の見出しだけがほかのセクションより左から始まり、ページの左の端がそろわないため。全部のセクションを広げる案は、お知らせや開催情報の文章の 1 行が長くなりすぎるので採らなかった

## grill-with-docs で決めること（中身の設計）

2026-10-14 に済ませた。結果は `docs/content-model.md` にまとめ、言葉は `GLOSSARY.md`、理由は `docs/adr/` に残した。

## 公開について

運営のメンバーにスマホで見てもらうには、モックを公開する必要がある。claude.ai の Artifact（非公開で作って、リンクを渡す）か、Cloudflare Workers のプレビューを想定している。どちらも外への公開になるので、進めてよいか確認したい。

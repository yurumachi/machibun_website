# 今の年と役割の決まり（ADR 0008）の確かめ方

`cms/src/plugins/admin-guard.ts` と `cms/src/middleware.ts` が、管理画面の操作を決まりどおりに通す・断るかを、画面から確かめる。EmDash を上げたときと、この2つを直したときに流す。

## 用意

1. 手元の開発サーバーを起動し、dev-bypass で管理者として入る（HANDOVER の「手元で動かす」）。
2. 管理者で、前の年（今の年 − 1）の出展者とカテゴリを1件ずつ作って公開する。
3. 実行委員として試すときは、手元の D1（`cms/.wrangler/state/v3/d1/` の、使っている DB）の `users` の `role` を 40 にし、開発サーバーを起動し直す。役割は起動し直すまで前の値が残る。終わったら 50 に戻して起動し直す。dev-bypass で入り直すのは、役割を変える前に済ませる。
4. プラグインのコードを直したら、開発サーバーを起動し直す。ファイルの保存だけでは、フックが新しくならない。

## 実行委員（Editor、40）

| | 操作 | 期待すること |
|---|---|---|
| E1 | サイドバーを見る | 「管理者」の見出し（プラグインの設定）が無い |
| E2 | カテゴリを新しく作って保存 | 「カテゴリとステージは、管理者だけが変えられます」で断られる |
| E3 | 今の年のカテゴリの名前を直して保存 | E2 と同じ |
| E4 | カテゴリを複製 | 「複製は、管理者だけができます」で断られる |
| E5 | カテゴリをゴミ箱へ | E2 と同じ |
| E6 | 出展者を、年を前の年にして新しく作る | 「年は（今の年）にしてください」で断られる |
| E7 | 出展者を、年はそのままで新しく作る | 保存できる |
| E8 | E7 の出展者の年を前の年に変えて保存 | E6 と同じ |
| E9 | E7 の出展者のひとことを直して保存 | 保存できる |
| E10 | E7 の出展者を公開 | 公開できる |
| E11 | 前の年の出展者のひとことを直して保存 | 「前の年の中身は、参考として残すので変えられません」で断られる |
| E12 | 前の年の出展者を非公開にする | E11 と同じ。公開のまま |
| E13 | 前の年の出展者を複製 | E4 と同じ |
| E14 | 前の年の出展者をゴミ箱へ | E11 と同じ |
| E15 | E7 の出展者をゴミ箱へ | ゴミ箱に移る |
| E16 | 出展者の「カテゴリ」の参照の候補を開く | 今の年のカテゴリだけが出る |
| E17 | ゴミ箱にある前の年の出展者（管理者が移したもの）を復元 | E11 と同じ。ゴミ箱に残る |
| E18 | ゴミ箱にある前の年の出展者を完全に削除 | E11 と同じ。ゴミ箱に残る |
| E19 | ゴミ箱にある今の年の出展者を復元 | 戻る |

## 管理者（Admin、50）

| | 操作 | 期待すること |
|---|---|---|
| A1 | カテゴリを新しく作って保存 | 保存できる |
| A2 | A1 のカテゴリをゴミ箱へ | ゴミ箱に移る |
| A3 | 前の年の出展者のひとことを直して保存 | 保存できる |
| A4 | 前の年の出展者をゴミ箱へ | ゴミ箱に移る |
| A5 | 前の年の出展者を複製 | 複製できる。年は前の年のまま写る |
| A6 | A5 の複製の年を今の年に直して保存 | 保存できる |
| A7 | カテゴリの一覧の画面を開く | 前の年のカテゴリも出る |
| A8 | プラグイン → admin-guard → 設定で、今の年を次の年にして保存し、出展者のカテゴリの候補を開く | 候補が無い（次の年のカテゴリが無いため） |
| A9 | 今の年を元に戻す | 候補が元に戻る |
| A10 | ゴミ箱にある前の年の出展者を完全に削除 | 消える |
| A11 | ゴミ箱にある前の年の出展者を復元 | 戻る |

## 結果

- 2026-11-01（EmDash 1.3.0、手元）: E1〜E19、A1〜A11 のすべてが期待どおりであった。agent-browser で画面を操作し、出た文と、API で読んだ状態で確かめた。
  - 最初の試しで、複製が保存のフックを通らず、前の年の年のまま実行委員の複製ができた。実行委員の複製を `middleware.ts` で断るように直した（ADR 0008）。
  - 前の年の中身の削除は、はじめ `content:beforeDelete` で全員に断っていたが、管理者は消せるように `middleware.ts` で実行委員だけを断る形に変えた。その過程で、実行委員がゴミ箱から前の年の中身を復元できることが分かり、復元も断るようにした（E17）。
  - 最後の直し（削除と復元を `middleware.ts` に移した）の後に流し直したのは、E14・E15・E17〜E19・A4・A10・A11。ほかの項目は、その前の版で流した。最後の直しでは、保存・公開・複製・候補の処理は変えていない。
  - 試していないこと: MCP からの操作。

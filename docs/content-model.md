# CMS に載せる中身（2026-10-14 時点）

grill-with-docs で決めたことと、まだ決まっていないことの一覧。言葉の定義は `GLOSSARY.md`、決めた理由は `docs/adr/` にある。

## 中身の種類と項目

どの種類も、何年の分かを持つ。年をまたいで同じものとしては扱わない（ADR 0003）。

| 種類 | 項目 | 入力する人 |
|---|---|---|
| 出展者 | 名前、出展カテゴリ、ひとこと、写真（最大3枚・1枚目は一覧にも出る）、紹介文、出展場所の番号、リンク（最大3つ）、前回の出展 | 出展者本人（編集用の鍵） |
| 出演者 | 名前、写真1枚、紹介文、リンク、前回の出展 | 出演者本人（編集用の鍵） |
| 出演枠 | 出演者、ステージ、開始・終了の時刻 | 管理者・実行委員 |
| ステージ | 名前 | 管理者 |
| 出展カテゴリ | 名前 | 管理者 |
| 協賛 | 企業名、ロゴ、リンク（押すと企業のサイトへ） | 協賛の担当者（編集用の鍵） |
| お知らせ | タイトル、日付、本文、一覧の上に固定するか | 管理者・実行委員 |
| 連絡先 | 代表者の名前、メールアドレス、電話番号 | 本人（編集用の鍵）・管理者 |

一つの出演者は、出演枠をいくつでも持てる。スケジュールは、その年の出演枠を時刻の順に並べたもの。

EmDash では、どの種類もコレクションにし、`cms/seed/seed.json` で定める。出展カテゴリとステージは、EmDash の分類（taxonomy）ではなく「年」を持つコレクションにした。分類には年を持たせられず、出展者が一つだけ選ぶ制約もかけられないため。出展カテゴリ・ステージ・出演者・前回の出展は参照の項目にする。連絡先はコレクションにしない（ADR 0002）。

## 誰が何をできるか

| | 管理者 | 実行委員 | 出展者・出演者・協賛 |
|---|---|---|---|
| 中身の編集と公開 | できる | できる | 自分の一件の下書きだけ |
| 出展者などの下書きを確認して公開する | できる | できる | ― |
| 編集用の鍵を発行する | できる | できる | ― |
| 連絡先を見る・消す | できる | できない | 自分の分だけ入力できる |
| 運営のアカウントとサイトの設定 | できる | できない | ― |
| 開催年を決める。出展カテゴリとステージを作る・直す・消す。過去の開催のデータを直す（ADR 0008） | できる | できない | ― |

- 出展者・出演者・協賛が保存した内容は下書きになり、運営が確認してから公開する。公開した後に書き直した場合も、確認するまでは前の内容のまま出る（ADR 0001）。
- 編集用の鍵は、管理者が年ごとに決める入力の締切まで使える。締切の後の修正は運営に頼んでもらう。なくしたら運営が再発行し、古い鍵は使えなくなる。
- 前回の出展として選べるのは、前の年に公開した出展者・出演者だけで、コピーできるのは公開した紹介文と写真だけ。運営の承認は要らない（ADR 0003）。
- 連絡先は、自作のプラグインの保存場所に置き、管理者だけが見られる。消すのは文化祭の後に管理者が手で行い、それより前のバックアップも手で消す（ADR 0002）。
- 協賛の過去は、年と企業名で検索して見る。

EmDash の役割との対応は、管理者が Admin、実行委員が Editor。出展者・出演者・協賛は EmDash の利用者にしない。

## ターミナルからの管理

- 中身・連絡先・編集用の鍵は MCP で扱う。連絡先と編集用の鍵は、自作プラグインの、管理者だけが使える MCP ツールにする。
- バックアップ・KV・D1 の確認は `cf` で扱う（npm 配布なので `cms/` の devDependencies に入れた）。D1 の中身を直接書き換えない。履歴・公開状態・検索の索引・キャッシュの更新が飛ばされるため。
- 運営のアカウント管理は管理画面で行う（MCP にユーザー管理がない）。
- wrangler と、REST API を直接呼ぶスクリプトは、今は入れない。一括で決まった処理をしたくなったら REST API のスクリプトを足す。

## 決まっていないこと

- 協賛に段階（ランク）を付けるか。付ける場合も、段階の名前をサイトに出すとは限らない
- 段階ごとの見せ方（バナー・ロゴの大きさ・名前だけ など）
- 広告を協賛と分けるか。広告は押すとリンク先に飛ぶようにする

## やらないこと

- 雨天時の切り替え（雨天でスケジュールは変わらない想定。必要になったら、出演枠に雨天時のステージと時刻を足し、サイト全体の切り替えを一つ置く）
- キャッチコピーを CMS で編集すること（HTML に直接書く）
